# VYRON AgentOS (code-server eklentisi)

code-server icinden VYRON AgentOS'a baglanir:

- Yan panelde AgentOS sohbeti (saglayici secimiyle)
- Secili kodu AgentOS'a sorma
- AgentOS notlarinda arama

Ayarlar `vyron.agentos.*` altindadir. Kullanim icin BENIOKU.txt dosyasina bakin.
Sirlar (sifre/token) yalniz VS Code ayarlarindan okunur, koda gomulmez.
